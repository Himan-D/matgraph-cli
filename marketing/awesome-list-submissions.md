# Awesome-list submissions (ready to paste)

Getting listed is the cheapest discovery there is: one merged line in a
curated list sends a steady trickle of installs forever. Submit in this order.

## 1. awesome-materials-informatics (highest value)

Repo: `tilde-lab/awesome-materials-informatics` (verify the path on GitHub
first — lists move). Find the section for ML potentials / property prediction
toolkits and open a PR adding, in that section's alphabetical spot:

```markdown
- [MatGraph](https://github.com/Himan-D/matgraph-cli) — Deep-learning toolkit for materials screening: M3GNet/MEGNet/CHGNet predictions, battery verticals, XRD, and a zero-config demo mode. CLI + SDK + GraphQL.
```

PR title: `Add MatGraph`. Body:

```markdown
MatGraph (MIT, PyPI: matgraph-cli) is a workflow layer over pymatgen/MatGL/mp-api:
one-line property prediction, cathode screening, XRD, dataset export, and a
served GraphQL API — with a `--demo` mode that runs with no API key. Docs:
https://himan-d.github.io/matgraph-cli/
```

## 2. Adjacent awesome lists

Search GitHub for `awesome materials` + `awesome chemistry` and file the same
one-liner wherever a tools/libraries section fits (e.g. computational-chemistry
lists, scientific-Python lists). One PR each; never mass-file without reading
each list's contribution rules.

## 3. After acceptance

- Add the list's badge/mention to the README (reciprocal links help SEO).
- Tick the item in `docs/growth.md`.

## Don't

- Don't pay for placement, don't astroturf, don't submit to lists with no
  curation standards — a link from a spam list is worth less than nothing.
